    <태블릿 환경의 웹 브라우저에는 자체적인 F12(개발자 도구) 기능이 내장되어 있지 않으므로, PC와 연결하는 원격 디버깅을 사용해야 합니다. 추가로 요청하신 그래프 데이터 내보내기 기능은 프론트엔드(JavaScript) 단에서 이미지나 데이터 파일 형식으로 다운로드하도록 구현할 수 있습니다. **태블릿 디버깅 (F12 대체 방법)** * **안드로이드 (Chrome):** 기기를 PC에 USB로 연결한 뒤, PC 크롬 브라우저 주소창에 `chrome://inspect/#devices`를 입력하면 태블릿에서 실행 중인 웹 페이지의 요소와 콘솔을 PC 화면에서 디버깅할 수 있습니다. * **아이패드 (Safari):** 기기를 Mac과 케이블로 연결한 뒤, Mac의 Safari 상단 메뉴에서 **개발자용 -> [기기 이름]**을 선택하여 웹 검사기를 실행합니다. **그래프 결과값 파일로 저장 (내보내기) 기능 구현** 사용 중인 라이브러리(Chart.js, ECharts 등)에 따라 내장된 내보내기 API가 있을 수 있으며, 일반적인 웹 환경에서는 다음 두 가지 방식을 주로 사용합니다. **1. 이미지(PNG/JPG)로 저장** HTML ``로 그려진 그래프 화면 자체를 캡처하여 저장하는 방식입니다. * Canvas 객체에서 `toDataURL('image/png')` 메서드를 호출하여 렌더링된 이미지의 URL 데이터를 추출합니다. * 자바스크립트로 보이지 않는 `` 태그를 생성한 뒤, `href`에 추출한 URL을 넣고 `download` 속성에 원하는 파일명(예: `chart_result.png`)을 지정합니다. * 해당 태그에 `click()` 이벤트를 강제로 발생시켜 사용자 기기에 파일이 다운로드되게 합니다. **2. 원본 데이터(CSV)로 저장** 그래프를 그리는 데 사용된 X축, Y축 등의 수치 데이터를 엑셀 등에서 열 수 있도록 내보내는 방식입니다. * 자바스크립트 내의 결과값 배열(Array) 데이터를 쉼표(,)로 구분된 CSV 형식의 문자열로 가공합니다. * `new Blob([데이터], { type: 'text/csv;charset=utf-8;' })` 코드를 사용해 문자열을 파일 객체(Blob)로 변환합니다. * `URL.createObjectURL(blob)` 함수로 다운로드용 링크를 생성한 뒤, `` 태그의 `download` 속성을 이용해 `result_data.csv` 형태로 저장합니다.
